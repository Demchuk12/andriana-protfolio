# Портфоліо Андріани Дацко

SvelteKit 3 + Svelte 5, статичний сайт (adapter-static). Дві мови (`/uk/`, `/en/`), світла та темна теми, мобільна версія.

## Команди

```bash
npm install
npm run dev       # локально: http://localhost:5173/uk/
npm run check     # перевірка типів
npm run build     # статичний сайт у папці build/
npm run preview   # переглянути зібрану версію
```

Папку `build/` можна залити на Vercel, Netlify, GitHub Pages чи будь-який статичний хостинг.

## Адмінка

Адреса: `/admin/`. Це [Sveltia CMS](https://sveltiacms.app/en/docs): бази даних і сервера немає, кожне збереження стає комітом у `main`, і Vercel сам перезбирає сайт (зміни видно приблизно за хвилину-дві).

### Налаштувати доступ (один раз, робить власник репозиторію)
1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. Repository access: **Only select repositories** → `andriana-protfolio`.
3. Permissions → Repository permissions → **Contents: Read and write**. Більше нічого.
4. Термін дії: максимальний зручний. Після завершення треба створити новий токен.
5. Передати токен приватно. На `/admin/` натиснути «Увійти за допомогою токена доступу» і вставити його. Браузер запам'ятає вхід.

Токен дає змогу змінювати вміст репозиторію, тому не публікуйте його й не зберігайте в коді. Якщо він потрапив до чужих рук, видаліть його на тій самій сторінці GitHub.

### Як користуватися
- **Додати тур:** «Напрямки та фото» → «Створити». Заповнити місто й країну, поставити точку на карті, додати фото, «Зберегти».
- **Фото:** можна перетягнути кілька одразу, з телефону теж. Вони самі стискаються до 1600px WebP.
- **Порядок:** кнопка «Змінити порядок».
- **Англійська** майже всюди необов'язкова (крім назви міста та імені): без перекладу покажеться українська.
- **Тексти, досвід, навички, контакти:** «Про мене та тексти».

Репозиторій публічний: видалені фото лишаються в історії git.

## Де що лежить

| Що | Де |
|---|---|
| Контент з адмінки | `src/content/` |
| Фото | `static/photos/` |
| Поля адмінки | `static/admin/config.yml` |
| Країни (назви + підсвітка на карті) | `src/lib/data/countries.ts` (той самий список у `config.yml`) |
| Тексти інтерфейсу (кнопки, меню) | `src/lib/i18n/uk.ts`, `src/lib/i18n/en.ts` |
| Кольори тем | `src/lib/styles/tokens.css` |
| Домен сайту (для SEO) | `src/lib/site.ts` |

## Нотатки щодо SvelteKit 3
- Конфіг лежить у `vite.config.ts` (`sveltekit({ adapter, ... })`), окремого `svelte.config.js` немає.
- Замість `$lib` використовується `#lib/...` (subpath imports у `package.json`) з явним розширенням файлу: `#lib/data/profile.ts`.
- Карта Європи рахується під час збірки (`src/lib/server/map.ts`), тож у браузер іде лише готовий SVG.
